## Objective

Develop a **deep neural network** that predicts athlete injury risk from 15 biometric, training, and lifestyle features, with **SHAP and LIME explainability** for model transparency, deployed as an interactive **Streamlit web application** with personalized recommendations.

---

## Architecture

A **Multi-Layer Perceptron (MLP)** with 4 hidden layers:

```
Input(15) → Dense(128,ReLU)+BN+Dropout(0.3)
           → Dense(64,ReLU)+BN+Dropout(0.3)
           → Dense(32,ReLU)
           → Dense(16,ReLU)
           → Dense(1,Sigmoid) → P(High Risk)
```

- **Module 1:** MLP (Multi-Layer Perceptron)
- **Module 2:** Autoencoder-inspired progressive compression (128→64→32→16)
- **Module 3:** Explainable AI (SHAP + LIME) + Streamlit Deployment

See [docs/Model_Architecture_Design.md](docs/Model_Architecture_Design.md) for the full layer-by-layer explanation and architecture diagram.

## Results

The evaluated DNN achieved **88.50% accuracy**, **0.7013 F1-score**, and
**0.9108 ROC-AUC** on the held-out 200-sample test set. It outperformed the
Logistic Regression baseline on accuracy, precision, recall, F1-score, and
ROC-AUC. The complete comparison is in
[`results/baseline_comparison.csv`](results/baseline_comparison.csv).

Evaluation metrics, training curves, confusion matrix, ROC curve, and baseline comparison are generated by running:

```bash
python evaluate.py                  # Basic evaluation
python notebooks/Evaluation.py     # Full evaluation with baseline comparison
```

All results are saved to `results/`. See [docs/FINAL_REPORT.md](docs/FINAL_REPORT.md) for the complete analysis.

## How to Run

### 1. Setup

```bash
python -m venv venv
venv\Scripts\activate              # Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
```

### 2. Prepare Data & Train

```bash
python preprocess.py Athlete.xlsx   # Preprocess: generates models/*.pkl
python train.py                     # Train: saves models/best_model.keras
python evaluate.py                  # Evaluate: generates results/ plots
```

### 3. Run EDA & Full Evaluation

```bash
python notebooks/EDA.py             # Generates EDA visualizations
python notebooks/Evaluation.py      # Full evaluation + baseline comparison
# Or open notebooks/EDA.ipynb and notebooks/Evaluation.ipynb in Jupyter.
```

### 4. Launch the Web App

```bash
streamlit run app.py
```

Opens at `http://localhost:8501` — enter athlete parameters, get predictions with SHAP/LIME explanations.
